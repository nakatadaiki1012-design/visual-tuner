# 🎵 VISUAL TUNER

**ピッチが合うと最高に気持ちいい**、エンタメ特化型のWebチューナーです。
`index.html` 1ファイルだけで動きます（インストール・ビルド不要）。

## 🚀 使い方

1. `index.html` をダブルクリックしてブラウザ（Chrome / Edge / Safari / Firefox）で開く
2. **🎤 マイクで始める** を押してマイクを許可 → 楽器を鳴らす
3. 針が真ん中（±3セント以内）に入ると **PERFECT!** → 合い続けるほど演出が激しくなります

> 💡 マイクが使えない場合：ブラウザによっては、ファイルを直接開くとマイクが禁止されます。
> GitHub Pages で公開するか、`python3 -m http.server` で `http://localhost:8000` から開いてください。
>
> 💡 デザイン用の Tailwind CSS とフォントはネットから読み込みます。オフラインでも動きますが、フォントは標準のものになります。

### キーボードショートカット
| キー | 動作 |
|---|---|
| `M` | マイク ON/OFF |
| `S` | 設定を開く/閉じる |
| `R` | 記録と実績を開く（画面右上の 🏆 ボタンでもOK） |
| `G` | テーマ一覧を開く（画面右上の 🎨 ボタンでもOK。🎲 おまかせもあります） |
| `1`〜`9` | テーマを番号で選ぶ |
| `←` `→` | 前／次のテーマへ |

スマホでは、**演出エリアを左右にスワイプ**するとテーマが切り替わります（左へ＝次、右へ＝前）。

### 🔓 テーマのアンロック（5種類ずつ解放）
- 最初に遊べるのは 1〜5番の **5種類**。
- その5種類をすべて **テーマLv.3** にすると、次の5種類（6〜10番）がアンロックされます。これを繰り返して全50種類へ。
- テーマLvは **マイクで練習したとき** に上がります。🎨テーマ一覧の上に、あと何種類か・各テーマのLvが表示されます。
- **全部すぐ使いたいとき**：設定画面のいちばん下にある小さな **🔑 ボタン** を押して、パスワード **`visualtuner`** を入力すると全テーマが解放されます。

### 🛠 管理者モード（ふだんは隠れています）
- 設定画面の **🔑 ボタン** で、パスワード **`tuneradmin`** を入力すると管理者モードになります。
- 管理者モードでできること：
  - **テスト音**（マイクなしで音を鳴らして演出を確認。画面上の 🔊 ボタン、スタート画面の「テスト音で試す」、`T` キー）
  - テスト音シンセの設定（音の高さ・わざとズラす・ゆらぎ・音量）
  - **全テーマが自動で解放**（管理者モードを終了すると、元のロック状態に戻ります）
- 設定画面の「管理者モードを終了」で、ふつうのモードに戻ります（テスト音は止まり、ボタンも隠れます）。

### 🎶 和音ボーナス（ハモり練習に）
- 設定の「和音ボーナス」で **メジャー / マイナー / セブンス** を選び、「根音」で和音の高さを選びます（例：根音C＋メジャー＝ド・ミ・ソ）。
- その和音の構成音を**純正の響き**（例：ミ＝−13.7¢、ソ＝+2.0¢）に合わせると、PERFECTになるのが速くなり、演出の盛り上がりも**1.5倍**になります（画面左上に「♪ 和音ボーナス ×1.5」）。
- 「和音のドローン音」をオンにすると、選んだ和音がずっと鳴るので、それに合わせてハモる練習ができます（**イヤホン推奨**。スピーカーだとマイクが拾ってしまうため）。
- ※ マイク1本で聞き取れるのは「いま鳴っている1つの音」なので、複数人の和音そのものではなく「選んだ和音に対して自分の音が合っているか」を判定します。

### ⭐ テーマレベル（音程が合えば合うほど、そのテーマが育つ）
- テーマごとに **Lv.1〜10** があり、そのテーマで音を合わせた時間で上がります。
- **ピッタリなほど速く上がります**：±1¢以内なら2倍、±2¢以内なら1.5倍の速さ。演出の盛り上がり（激しさ）も、ピッタリなほど速く最大になります。
- レベルが上がると：
  - **Lv.2〜**：まわりを回る光のオーラ（銅 → 銀 → 金 → Lv.10で虹色）。粒の量も少しずつ増える
  - **Lv.3 / 6 / 9**：そのテーマ専用の新しい演出が解放（例：ネオン＝ホログラム六角形→天井のレーザー→虹色レーザーショー、シューター＝ウィングマン→ダブルショット→虹色レーザー、ねこ＝子ねこ→毛糸玉→王冠）
- 画面左上に「★ テーマLv」と次のレベルまでのゲージ、テーマ一覧に各テーマのレベルが表示されます。
- ※ テーマレベルも、マイクで練習したときだけ上がります。

### 📚 テーマごとのコレクション
**全50テーマに「段階」があります。** ピッタリ合わせ続ける（約15秒ごと）と次の段階へ進み、景色・仲間・道具などが増えていきます。左上に「いまの段階 ・ 次は〇〇」と進み具合のバーが出ます。

すべてのテーマの「段階」（相棒モンスター・花・花火・万華鏡の模様・海の仲間・雪の結晶・武器・焚き火・風船の色・星座図鑑・書いた字・追い抜いた車・猫種・野菜・初日の出・通過した駅・桜の成長・歯車の数・倒したモンスターのレベルなど）は、すべてブラウザに保存されて次回も続きから遊べます。🏆 記録画面の「テーマのコレクション」で一覧できます。

- **FEVER TIME**：10秒を超えると画面のふちが虹色に光り、星が降りそそぐ
- **レベルと称号**：PERFECTの合計時間で経験値が貯まり、見習い → ルーキー → チューニング職人 → … → 伝説の調律師
- **自己ベスト更新**：いちばん長く合わせ続けた記録を超えると、紙吹雪でお祝い
- **実績バッジ（22個）**：「10秒キープ」「12音コンプリート」「1週間連続」など
- **記録画面（🏆ボタン）**：レベル、自己ベスト、累計時間、今日の練習時間、連続練習日数、12音コレクション、実績の一覧
- ※ レベル・実績などの記録は **マイクで練習したときだけ** 貯まります。記録はこの端末のブラウザに保存されます。

### 共通の演出
- **パーフェクト・ホールド**：±3セントに留まった秒数で「PERFECT 1s… 2s… 3s!!」とコンボが伸び、演出がどんどん激しくなります（6秒で最大）
- **オーディオリアクティブ背景**：音量で波紋や光の粒が脈動し、倍音が多いほど粒が増え、線が太くなります

### チューナー機能
- **高精度ピッチ検出**：自己相関法（正規化自己相関／McLeod法）＋放物線補間。テストでの誤差は0.2セント以下
- **ノイズゲート**：一定の音量より小さい音は無視（設定の「マイク感度」で調整）
- **純正律モード**：根音を選ぶと、その和音で美しくハモる目標（長3度 −13.7¢、完全5度 +2.0¢ など）がメーター上にガイドとして表示されます
- **倍音スペクトル**：基音〜第5倍音をバーで表示し、「クリアな響き」「バランスの良い響き」「倍音豊か！」を判定
- **移調楽器**：C（実音）/ B♭ / E♭ / F の記音表示
- **基準ピッチ**：440Hz / 442Hz / 415Hz（古楽ピッチ）
- **セントメーターの見た目**：設定の「セントメーターの見た目」で **バー / アナログ針 / LED / ストロボ / デジタル数字 / 丸ダイヤル** から選べます
- **テスト音シンセ（管理者モードのみ）**：A4 などのサイン波を再生。「わざとズラす」スライダーや「ゆらぎ」で、ロックが外れる様子も確認できます

## ⚡ 重さ対策（処理落ちしにくい仕組み）

- **ピッチ検出の高速化**：自己相関を FFT（高速フーリエ変換）で計算するようにして、解析の処理時間を約 1/6 にしました（精度は同じ）。
- **自動画質調整**：設定の「画質」が「自動」のとき、カクつきを検知すると **高画質 → 標準 → 軽量** と自動で下げます。軽くなった状態が続くと元に戻ります。
  - 下げる内容：光のにじみ（いちばん重い処理）、パーティクルの数、画面の解像度
- 手動で「高画質／標準／軽量」に固定することもできます。設定画面に、いまの fps と画質が表示されます。
- **ヌルヌル動かす工夫**：
  - 針や演出のズレ表示を「バネ」の動きで追いかけるので、音が揺れてもなめらかに動きます
  - フレームごとの時間のばらつきをならして、動きのカクつきを抑えます
  - 動く背景の上の「ぼかし」は重いので、パソコンで高画質のときだけ使います（スマホでは自動でオフ）
  - 画質の自動調整は、描画そのものが重いときにも反応します（30fps固定の端末は除く）
  - 粒の再利用、花びらの描画の効率化、軽量・標準画質ではピッチ解析を1フレームおきに
- **画面のゆれ**：合った瞬間などに画面がゆれる演出は、設定の「画面のゆれ」で **自動／ふつう／弱め／なし** を選べます。「自動」はスマホでは控えめになります。
- スマホでも見やすいように、表示する文章の長さが変わっても演出エリアやボタンの位置が動かないようにしています。

## 🎨 カスタマイズ方法（コードがわからなくても大丈夫）

`index.html` をメモ帳（Windows）や テキストエディット（Mac）、VS Code などで開いて、
**数字や色の文字を書き換えて保存 → ブラウザを再読み込み** するだけです。
（`Ctrl + F` / `⌘ + F` で下の「探す文字」を検索すると、すぐ見つかります）

### ⓪ アンロックの条件・パスワードを変える
探す文字：`const UNLOCK_GROUP`

| 項目 | 今の値 | 意味 |
|---|---|---|
| `UNLOCK_GROUP` | `5` | 何種類ずつ解放するか |
| `UNLOCK_LV` | `3` | 各テーマを何レベルにすれば次が解放されるか |
| `UNLOCK_PASS` | `'visualtuner'` | 全テーマ解放のパスワード（好きな言葉に変えられます） |
| `ADMIN_PASS` | `'tuneradmin'` | 管理者モードのパスワード |

### ① 判定の厳しさ・演出のテンポを変える
探す文字：`const CONFIG`

| 項目 | 今の値 | 意味 | 例 |
|---|---|---|---|
| `LOCK_CENTS` | `3` | ±何セントで PERFECT にするか | 初心者向けなら `5`、上級者向けなら `2` |
| `MAX_INTENSITY_SEC` | `6` | 何秒合わせ続けると演出が最大になるか | すぐ派手にしたいなら `3` |
| `LOCK_GRACE_MS` | `180` | 一瞬外れてもコンボを切らない時間（ミリ秒） | ビブラートを多めに許すなら `400` |
| `CLARITY` | `0.80` | 音を認識する厳しさ | 反応が悪いなら `0.7` |
| `MAX_PARTICLES` | `900` | 粒の最大数 | スマホが重いなら `400` |
| `TIMBRE_CLEAR` / `TIMBRE_RICH` | `0.06` / `0.22` | 音色判定のしきい値 | |
| `COMBO_WORDS` | `NICE`(3秒)〜`GODLIKE`(12秒) | ホールド秒数で出る称号 | `[5,'すごい！']` のように日本語もOK |

### ② 演出の色を変える
探す文字：`palette:`（各テーマに1つずつあります）

```js
palette:{ bg:'#05020d', flat:'#00f0ff', sharp:'#ff2bd6', good:'#2bff9a', ... }
```

| 名前 | 意味 |
|---|---|
| `bg` | 背景色 |
| `flat` | 音が**低い**ときの色 |
| `sharp` | 音が**高い**ときの色 |
| `good` | **合っている**ときの色 |
| `idle` | 音が鳴っていないときの色 |
| `reactive` | 背景の波紋・光の粒の色（3色） |

色は `#` から始まる6桁のカラーコードです（「カラーコード 一覧」で検索すると選べます）。
ボタンやパネルの色は、ファイル上部の `body[data-theme="neon"]` などの行（`--accent` など）で変えられます。

### ③ 各テーマの演出を細かく変える

| やりたいこと | 探す文字 | 変えるところ |
|---|---|---|
| ネオンのレーザーの本数 | `const n=2+Math.floor(S.intensity*10` | `10` を大きくすると本数が増える |
| ネオンの火花の量 | `this.sparks(60,900)` | `60` が合った瞬間の火花の数 |
| 流星群の量 | `this.met+=dt*(2+S.intensity*22)` | `22` を大きくすると流星が増える |
| 8bitのポップアップ文字 | `'CRITICAL HIT!'` / `'MISS...'` / `'LEVEL UP!'` | 好きな言葉に（日本語は表示されないフォントなので英数字推奨） |
| 8bitのコンボの増え方 | `S.hold*20` と `n*20` | 1秒あたり20コンボ（5秒で100 COMBO!） |
| 8bitのモンスターの形 | `SPR:` | `X`=体 `o`=輪郭 `D`=影・翼 `W`/`E`=目 `M`=口 `K`=角 `C`=金 `.`=透明 のドット絵 |
| 花びらの枚数・大きさ | `LAYERS:` | `n:12` が枚数、`len` が長さ、`w` が太さ |
| 舞い散る花びらの量 | `this.acc+=dt*(3+S.intensity*22)` | `22` を大きくすると増える |
| 花火の色 | `COLORS:['#ff4f6d'` | 花火に使う色の一覧 |
| 花火の連発の速さ | `(0.8+S.intensity*3.5)` | `3.5` を大きくすると連発が増える |
| ストロボの回転の速さ | `clamp(S.devDisp,-50,50)*0.05` | `0.05` を大きくすると速く回る |
| 万華鏡の模様と対称の数 | `STAGES:` の `N:` | `N:8` を `6` や `12` に |
| クラゲの数 | `this.jelly=Array.from({length:6}` | `6` を好きな数に |
| 波の荒れやすさ | `0.03+0.2*clamp(Math.abs(S.devDisp)/40` | `0.2` を大きくすると荒波に |

### ④ 新しいテーマを追加する（ちょっと上級）
`THEMES` の中の1テーマ（例：`snow: { ... },`）を丸ごとコピーして名前を変えれば、51個目のテーマとしてテーマ一覧に自動で並びます（アンロックは5種類ずつなので、最後のグループに入ります）。
各テーマは次のパーツでできています：

- `bg` … 背景を描く
- `main` … メインの絵（メーター・惑星・花など）を描く
- `onLock` … 合った瞬間の演出
- `onMilestone(n)` … 合い続けて n 秒ごとの演出
- `onBreak` … 外れたときの演出

ボタンやパネルの色は `palette` から自動で作られます。変えたいときは `ui:{ accent:'#ff0000' }` のように書き足してください（`snow` や `balloon` が参考になります）。
