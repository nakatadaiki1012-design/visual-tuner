# 🌸 「春」鑑賞ノート

ヴィヴァルディ《四季》より「春」第1楽章の鑑賞教材アプリです。
**先生が授業で使う**ことも、**生徒がひとりで取り組む**こともできます。

## 使い方
- `index.html` と `spring.mp3` を同じフォルダに置いて、`index.html` をブラウザで開く
  （GitHub Pages では `…/vivaldi-spring/` を開く）
- インストール・ネット接続は不要です
- URL の最後に `?mode=student` / `?mode=teacher` をつけると、そのモードで直接開きます

## 🧑‍🎓 ひとりで学ぶ（6ステップ）
1. まず聴いてみよう（感じたことばを選ぶ・書く）
2. 詩と音楽（ソネットの行をタップするとその場面が流れる）
3. 場面あてクイズ（5問）
4. 主題をさがせ（春の主題がもどってきたらボタン → リトルネロ形式）
5. 音楽のしくみ（トリル・トレモロ・音階・強弱などを選んで答え合わせ）
6. 紹介文を書こう（印刷・PDF保存・コピー）

書いた内容は端末（ブラウザ）に自動保存されます。

## 🧑‍🏫 授業で使う
- 提示画面：アニメーション＋場面名・詩・聴きどころ。場面ボタンで頭出し、くり返し再生
- 「場面名をかくす」で「何の場面？」と問える
- みんなでクイズ（答えはボタンで表示）、主題さがしゲーム（クラス版）
- 指導の流れ（2時間扱いの例・発問例・評価の視点）
- 設定：場面の時間合わせ、別の録音の読み込み、白紙ワークシート印刷
- キーボード：Space 再生／← → 場面移動／1〜0 場面ジャンプ／L くり返し／H かくす／F 大きく映す

## 音源
ルイス・カウフマン（独奏ヴァイオリン）、ヘンリー・スウォボダ指揮 コンサートホール室内管弦楽団（1947年録音）。
場面の時間はこの録音に合わせています。
